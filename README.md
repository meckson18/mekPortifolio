This portfolio presents Meckson's profile, skills, contact information, and a project section that is ready for future work. The current project list is intentionally empty and can be updated when portfolio projects are available.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
